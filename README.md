# Spinneys Hot Food

Static GitHub Pages website for Spinneys Hot Food.

## Files
- `index.html` - website
- `styles.css` - design
- `app.js` - search/filter/grouping
- `data/products.json` - product JSON
- `images/` - optional product images named by item code

## GitHub Pages
Upload these files to the root of a GitHub repository, then enable GitHub Pages from `Settings -> Pages` using `Deploy from a branch`, branch `main`, folder `/ (root)`.

For a project repository called `spinneys-hot-food`, the URL is:
`https://YOUR-USERNAME.github.io/spinneys-hot-food/`
